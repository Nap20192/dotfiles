## Базовое

| Клавиша | Режим | Действие |
|---|---|---|
| `jk` | insert | Выйти в normal |
| `;` | normal | `:` — командный режим |
| `<leader>?` | n | Открыть этот файл |
| `<leader>d` | n | Включить/выключить диагностику |
| `<localleader>sc` | n | Включить/выключить проверку орфографии (`ru_ru,en_us`) |
| `gx` | n | Открыть URL под курсором |
| `gx` | v | Открыть URL в выделении |
| `gV` | n | Выделить последний вставленный/изменённый текст |

Скролл (`<C-u>`, `<C-d>`, `<C-f>`, `zt`, `zz`, `zb`) — обычный, без анимации.
`scrolloff=999`, поэтому курсор всегда держится по центру экрана.

### Копирование путей

| Клавиша | Режим | Действие |
|---|---|---|
| `<leader>cp` | n | Относительный путь файла → буфер обмена |
| `<leader>cP` | n | Абсолютный путь файла |
| `<leader>cp` | v | Относительный путь + номера строк (`./path:10-20`) |
| `<leader>cP` | v | Абсолютный путь + номера строк |

## Файлы и деревья

### neo-tree — основное дерево

| Клавиша | Действие |
|---|---|
| `<C-b>` или `<leader>nt` | Открыть/закрыть дерево (справа, ширина 34) |
| `<leader>nr` | Показать текущий файл в дереве |
| `<leader>nb` | Список буферов деревом |
| `<leader>ng` | Git-статус деревом |

**Внутри окна neo-tree:**

| Клавиша | Действие |
|---|---|
| `<CR>` / `l` / `o` | Открыть |
| `h` | Свернуть узел |
| `s` / `S` | Открыть в vertical / horizontal split |
| `t` | Открыть во вкладке |
| `P` | Превью в плавающем окне |
| `a` / `A` | Создать файл / каталог |
| `d` / `r` | Удалить / переименовать |
| `y` / `x` / `p` | Копировать / вырезать / вставить |
| `H` | Показать/скрыть скрытые файлы |
| `z` | Свернуть все узлы |
| `R` / `q` / `?` | Обновить / закрыть / помощь |
| `<leader>ks` | Добавить выбранные записи в контекст Claude |

### mini.files

| Клавиша | Действие |
|---|---|
| `<leader>m` | Открыть на текущем файле |
| `<leader>M` | Открыть на cwd |

**Внутри:** `l` войти, `<CR>` войти+открыть, `h` / `H` наверх, `q` закрыть,
`=` применить изменения, `<BS>` сброс, `@` показать cwd, `m` / `'` метка / переход,
`<` / `>` подрезать колонки, `g?` помощь.

### netrw

`<leader>e` — `:Explore`. Древовидный режим, баннер выключен.

## AI: Copilot и Claude Code

Два разных префикса: Copilot — `<leader>a*`, Claude Code — `<leader>k*`.

### Copilot — inline-подсказки

| Клавиша | Режим | Действие |
|---|---|---|
| `<M-l>` | i | Принять предложение |
| `<M-w>` | i | Принять одно слово |
| `<M-]>` / `<M-[>` | i | Следующее / предыдущее |
| `<M-h>` | i | Отклонить |
| `<M-CR>` | i | Открыть panel |
| `<leader>aa` | n | Toggle |
| `<leader>ae` / `<leader>ad` | n | Включить / выключить |
| `<leader>ar` | n | Перезапустить |
| `<leader>as` | n | Статус |
| `<leader>ap` | n | Panel |

Автотриггер включён, но только для явного списка filetype (go, python, lua, rust,
js/ts, sh, make, sql, proto, yaml, markdown, gitcommit); для остальных — `["*"] = false`.
Отключается целиком через `vim.g.copilot_disable = true`.

### Claude Code — сессия рядом с редактором

Claude запускается **не внутри Neovim**: в панели tmux справа (если nvim в tmux)
или в отдельном окне kitty.

| Клавиша | Режим | Действие |
|---|---|---|
| `<leader>kk` | n | Старт / стоп сессии |
| `<leader>kf` | n | Фокус (для внешнего терминала = то же, что `kk`) |
| `<leader>kr` | n | Продолжить сессию (`--resume`) |
| `<leader>kc` | n | Продолжить последнюю (`--continue`) |
| `<leader>km` | n | Выбрать модель |
| `<leader>kb` | n | Добавить текущий буфер в контекст |
| `<leader>ks` | v | Отправить выделение в контекст |
| `<leader>ks` | n, в neo-tree | Добавить выбранные файлы из дерева |
| `<leader>ky` | n | Принять дифф |
| `<leader>kn` | n | Отклонить дифф |
| `<leader>kS` | n | Статус подключения |

Правки от Claude приходят вертикальным диффом. Внутри диффа можно править текст
до принятия; `:w` тоже принимает, `:q` — отклоняет.

Команды без биндов: `:ClaudeCodeAdd <файл> [start] [end]`, `:ClaudeCodeOpen`,
`:ClaudeCodeClose`, `:ClaudeCodeStart`, `:ClaudeCodeStop`, `:ClaudeCodeCloseAllDiffs`.

## Git

Fugitive и друзья — на дефолтных командах, своих биндов нет.

| Команда | Действие |
|---|---|
| `:Git` | Статус |
| `:Git commit`, `:Git push` | Как в CLI |
| `:Git blame` | Blame текущего файла |
| `:Gvdiffsplit` / `:Ghdiffsplit` | Дифф с индексом vertical / horizontal |
| `:GBrowse` | Открыть файл/строку в GitHub / GitLab / Bitbucket |
| `:Gwrite` / `:Gread` | `git add` / `git checkout` для файла |

**В окне `:Git`:** `s` stage, `u` unstage, `-` toggle, `cc` commit, `dv` дифф,
`=` развернуть, `X` откатить.

Запуск внешних команд — `:Dispatch <cmd>`, результат уходит в quickfix.

## Чего здесь нет

Раньше в этом файле было описано то, чего в конфиге не существует. Чтобы не искать зря:

- **obs.nvim** и бинды `<leader>n*` для заметок — плагин не установлен
  (`<leader>n*` теперь принадлежит neo-tree);
- **oil.nvim** и бинд `-` — плагин ставится, но его конфиг целиком закомментирован;
- **treesitter text objects** (`af`/`if`, `ac`/`ic`, `]f`/`[f`, swap параметров,
  фолдинг по treesitter) — секция закомментирована;
- **тесты и бенчмарки на `<localleader>t*` / `<localleader>b*`** — каталога
  `ftplugin/` в репозитории нет, эти бинды не создаются;
- **fzf-lua бинды** `<leader>fs`, `<leader>fd`, `<leader>fq`, `<leader>fh` и прочие —
  не определены, используй команды `:FzfLua *`;
- **`<leader>ut`** для undotree — бинда нет, есть команда `:Undotree`;
- **`:DiffOrig`** — команды нет, есть `:DiffTool`;
- **переключение вкладок `<A-h>` / `<A-l>`** — эти клавиши перехвачены mini.tabline
  под переключение буферов, вкладки переключаются `gt` / `gT`.

Подробности — в разделе «Известные расхождения» в [README.md](./README.md).
