# Урок 2 — Диффы (diffview)

Смотреть что изменилось: до коммита, между ветками, в любой ревизии.

## Рабочий дифф

| Клавиши | Действие |
|---|---|
| `Space gv` | `:DiffviewOpen` — весь несмерженный дифф против HEAD |
| `Space gV` | закрыть diffview |

В diffview слева панель файлов, справа — дифф текущего файла:

| Клавиша | Действие |
|---|---|
| `j`/`k` + `Enter` | ходить по файлам / открыть |
| `Tab` / `S-Tab` | следующий / предыдущий файл |
| `-` | stage/unstage файл прямо из панели |
| `g?` | справка |
| `]c` / `[c` | следующий / предыдущий изменённый кусок в дифФе |

## Дифф против конкретной точки

```vim
:DiffviewOpen main            " всё, что изменилось относительно main
:DiffviewOpen main...HEAD     " изменения ТВОЕЙ ветки (с точки ветвления)
:DiffviewOpen HEAD~3          " против трёх коммитов назад
```

`main...branch` (три точки) — главный инструмент ревью ветки/worktree
перед merge (см. урок 4).

## Дифф одного файла (fugitive)

```vim
:Gvdiffsplit          " текущий файл: рабочая версия vs индекс
:Gvdiffsplit main     " текущий файл vs его версия в main
```

В режиме vimdiff работают нативные:
- `]c` / `[c` — следующее/предыдущее отличие
- `do` (diff obtain) — забрать кусок из соседней панели
- `dp` (diff put) — отдать кусок в соседнюю панель

`do`/`dp` — это ручной перенос изменений между версиями, пригодится в
конфликтах (урок 4).

**Практика:** поменяй файл → `Space gv` → пройди `]c` по кускам → `-` в
панели файлов для staging → `Space gV`.
