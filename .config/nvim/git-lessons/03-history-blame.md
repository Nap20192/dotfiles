# Урок 3 — История и blame

Кто, когда и зачем менял код.

## Blame

`Space gb` — `:Git blame`: слева колонка с коммитом/автором/датой для
каждой строки текущего файла.

В окне blame:

| Клавиша | Действие |
|---|---|
| `Enter` | открыть коммит под курсором |
| `o` | открыть коммит в сплите |
| `-` | re-blame от родителя этого коммита (копать глубже в прошлое) |
| `q` | закрыть blame |

`-` — ключ к вопросу «а что было ДО этого рефакторинга»: blame показывает
последний коммит строки, а `-` перематывает до предыдущего изменения.

## История

| Клавиши | Действие |
|---|---|
| `Space gl` | `:Gclog` — лог репозитория (или выделения в visual!) в quickfix |
| `Space gL` | `:Gclog %` — история текущего файла |
| `Space gh` | `:DiffviewFileHistory %` — история файла с диффами (красивее) |
| `Space gH` | `:DiffviewFileHistory` — история всего репо с диффами |

Выделил функцию в visual → `Space gl` — история только этих строк
(`git log -L` под капотом). Это ответ на «когда сломали эту функцию».

По quickfix-логу ходишь `]q` / `[q` (урок про quickfix ты уже знаешь).

В твоём fugitive-конфиге в окнах коммитов есть ещё:
- `dt` — дифф ревизии под курсором в новой вкладке
- `<localleader>rs` — soft reset на ревизию под курсором

## Открыть файл из прошлого

```vim
:Gedit main:%        " текущий файл, версия из main
:Gedit HEAD~5:%      " версия 5 коммитов назад
:Gedit abc1234:path/to/file.go
```

Читаешь старую версию как обычный буфер, дифф с ней — `:Gvdiffsplit`.

**Практика:** открой любой файл → `Space gb` → Enter на строке → посмотри
коммит → `-` перемотай глубже → `q`.
