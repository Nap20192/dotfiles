# Урок 1 — Статус, staging, коммит (fugitive)

Ежедневный цикл: посмотрел → застейджил → закоммитил. Всё не выходя из nvim.

## Открыть статус

`Space gg` — окно статуса fugitive (аналог `git status`).

Внутри окна статуса (курсор на файле):

| Клавиша | Действие |
|---|---|
| `s` | stage файл (или выделенные в visual) |
| `u` | unstage |
| `-` | переключить stage/unstage |
| `=` | развернуть inline-дифф файла прямо тут |
| `>` / `<` | открыть/закрыть дифф |
| `dv` | открыть файл в vertical diff (staged vs working) |
| `X` | discard изменения файла (осторожно!) |
| `Enter` | открыть файл |
| `g?` | вся справка по клавишам |

Stage по кускам: разверни дифф через `=`, выдели строки в visual (`V`),
нажми `s` — застейджатся только они. Это замена gitsigns-хankов.

## Коммит

Из окна статуса: `cc` — коммит (у тебя настроен `--verbose`: в буфере
сообщения виден весь дифф). Пишешь сообщение, `:wq` — коммит создан.

Другие варианты из статуса:
- `ca` — amend с редактированием сообщения
- `ce` — amend без редактирования (докинуть файлы в последний коммит)

Или из любого места: `:Git commit`, `:Git commit --amend`.

## Пара команд без окна статуса

```vim
:Gwrite      " stage текущий файл (git add %)
:Gread       " откатить буфер к индексу (git checkout %)
:Git <что угодно>   " любая git-команда, вывод в сплите
```

**Практика:** поменяй два файла → `Space gg` → застейджи один целиком, во
втором — только пару строк через `V`+`s` → `cc` → напиши сообщение → `:wq`.
